# URL-Wrapper

> A lightweight Chrome extension that brings VS Code-style word wrapping to long URLs.

Long, unformatted URLs in web pages or API documentation can be messy and hard to read. **URL Wrap** lets you toggle a clean, formatted dark-mode overlay directly on any web page with a quick keyboard shortcut.

---

## ✨ Features

* **VS Code-style Wrapping:** Breaks long query parameters, tokens, and deep links cleanly without breaking functionality.
* **Keyboard Shortcut (`Alt + Z`):** Instant overlay toggle—no extra clicks required.
* **Dark Mode Design:** Monospace syntax-highlighted theme built for easy reading.
* **Non-Intrusive:** Light on resources; runs only when invoked.
